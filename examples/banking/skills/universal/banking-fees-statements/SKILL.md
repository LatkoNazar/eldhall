# Fees and statements
Search published sandbox knowledge for fee, document and statement questions, then cite the source used. Clearly separate the synthetic tariff example from a real bank tariff.
For a statement request, clarify the desired period and format. No statement-generation or email-sending tool is installed in the base sandbox. An answer about how to request a statement must not claim that a PDF was generated or delivered. Escalate the actual document operation. Never invent a fee waiver, account balance, loan decision or individualized financial recommendation.
