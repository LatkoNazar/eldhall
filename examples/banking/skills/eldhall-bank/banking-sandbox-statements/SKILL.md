# Як запросити виписку
У тестовому Eldhall Bank Sandbox для запиту виписки слід вказати потрібний період і формат: електронний або паперовий. Секрети картки для цього не потрібні.
Базовий агент може пояснити порядок запиту й передати його оператору. Інструмент створення PDF або відправлення листів не підключено, тому готовий документ чи доставку не можна підтверджувати без результату відповідної інтеграції.
